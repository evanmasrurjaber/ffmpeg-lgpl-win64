# FFmpeg-Builds stages the lgpl-min build drops (D-045). One script per line, relative to
# upstream/scripts.d/. overlay/apply.sh appends `ffbuild_enabled() { return -1; }` to each,
# so the library is not built and generate.sh passes its --disable-... flag to configure.
#
# Listed: every stage the upstream win64 lgpl 9.0 build enables that we do not keep, and
# every script of a dropped folder stage. Stages that are only dependencies of dropped
# stages (libogg, brotli, pcre2, ...) are not built once their users are gone, so they are
# not listed. A stage that upstream adds later is caught by overlay/allowed-libs.txt.
